# Challenge modes

Status: idea.

## What it does

Other rulesets next to the normal run: a daily or weekly seed, score attack
rules, endurance, a mode without gold, and so on.

## Why it is interesting

Replayability without new content, and a seeded run lets players compare on
equal terms.

## What it would touch

Run setup, random spawning, and the menu.

## Open questions

- Which modes first? The original vision lists a lightweight seed as nice to
  have for the demo.
- Do modes get their own high scores?
