# Tutorial and end card

Status: idea.

## What it does

A short tutorial beat before the first run, and an end card for the demo that
shows the score and what is coming in the full game. Links to the creator's
and the game's socials go there too.

## Why it is interesting

The original vision's complete loop is menu, tutorial beat, run, game over and
one more run. The end card makes the demo shareable.

## What it would touch

The menu and game over flow.

## Open questions

- How short can the tutorial be, and is it skipped after the first run?
- Game analytics for the demo test, which the original vision marks as a maybe.
