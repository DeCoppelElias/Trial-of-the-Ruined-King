# Composition root

Status: not started.

Builds the [composition root](../ideas/composition-root.md) idea. Its grill
settles the `composition-root` decision, then the code changes to follow it
fully. It depends on the [ports and adapters](ports-and-adapters.md) and the
[domain events](domain-events.md). It is bound by the decisions of every entry
it depends on.
