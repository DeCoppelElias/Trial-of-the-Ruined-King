# Frame rate independence

Status: not started.

Builds the [frame rate independence](../ideas/frame-rate-independence.md)
idea. Its grill settles the `frame-rate-independence` decision, then the code
changes to follow it fully. It depends on the [game clock](game-clock.md) and
the [attack lifecycle](attack-lifecycle.md). It is bound by the decisions of
every entry it depends on.
