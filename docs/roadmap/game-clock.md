# Game clock

Status: done.

Builds the [game clock](../ideas/game-clock.md) idea. Its grill settles the
`game-clock` decision, then the code changes to follow it fully. It depends on
the [ports and adapters](ports-and-adapters.md). It is bound by the decisions
of every entry it depends on. It replaces the time scale delegates that
`Bootstrap` passes to the presenters.
